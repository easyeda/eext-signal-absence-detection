# 信号缺失检测助手 (Signal Absence Detection)

EasyEDA Pro（嘉立创EDA专业版）原理信号评审扩展：一键检测**当前图页所属板子**的全部原理图页，识别**单连接 / 悬空网络**并沿导线描线高亮，生成可定位的检测报告。

## 核心能力：合并既有导线连接，识别独立的单网络标签

**合并器件原有的导线连接关系**：检测先建立完整的网络连通关系——导线按几何连通性分组（端点重合 / T 型连接），再合并网络标签 / 端口同名连通组（跨岛 / 跨图页）、短接符号桥接的连通组。器件之间**已经用导线直连**的关系会被完整并入同一网络，不会拆开重复统计，也不会因此误报。

**识别独立的单网络名字（无对端悬空标签 / 悬空电源名）**：网络标签 / 电源标识符的作用是代替导线直连。合并完成后，若某一网络名在整张原理图内**仅覆盖 1 个连通组**——即名字没有连到任何对端——则判为独立悬空名字并报告；此时即使该组内器件之间已有导线直连（如 R13 与 U8 直连、其上挂的 `EN2.8V` 标签），名字也没有建立任何连接，照样报告。电源标识符同样适用（如误输入的电源名 `MCU_3V3123`，仅挂 1 个连通组、全图无对端）。网络名覆盖 ≥ 2 个连通组则视为名字生效，不报告。

| 场景 | 网络名覆盖岛数 | 判定 |
|------|:---:|------|
| `EN2.8V` 标签挂在 R13—U8 直连导线上，别处无同名 | 1 | ✅ 报告（独立悬空标签） |
| `EN5.0V` 标签同时出现在主网络与 U5 引脚处 | 2 | 不报告（标签生效） |

## 检测项

| 类型 | 说明 | 示例 |
|------|------|------|
| 单连接 | 有名网络器件数 ≤ 阈值（默认 1）；或单一网络名仅覆盖 1 个连通组（悬空标签/悬空电源名） | MCU 引脚 + 网络标签，标签无对端（如 `OSC_IN`、`UART_TXD`）；R13 与 U8 直连导线上的 EN2.8V 标签无对端；误输入的电源名 `MCU_3V3123` 无对端 |
| 无器件连接 | 有名网络 0 器件连接 | 悬空网络标签 / 网络端口 |
| 未命名网络 | 空网络名孤立导线仅连 1 个器件 | 开关悬空的一侧 |
| 悬空导线 | 无任何连接的孤立导线 | 误放置的导线段 |
| 孤立引脚 | 未连任何导线、且无非连接（noConnect）标识的引脚 | 漏连的器件引脚 |

## 判定规则

- **作用域 = 单张原理图（跨图页）**：同名网络标签 / 端口跨图页出现即视为同一网络（多图页连接的正确表达）；不同原理图之间不合并。检测范围 = 当前图页所属板子（其原理图下全部图页），其余板子不检测；跨板残留标记可用「清除高亮」一次性移除。
- 导线先按**几何连通性**分组（端点重合 / 端点落线段的 T 型连接；十字交叉不合并），再按网络名跨图页合并。
- **短接符号（Short-Symbol）两引脚间视为导线直连**：桥接的连通组跨岛合并、网络名互通（如 PA9 与 UART_RXD 经短接符号相连即为同一网络），且不计入器件数。
- **网络标签 / 端口代替导线直连**：标签/端口的网络名并入所在连通组，同名连通组跨岛 / 跨图页合并；标签直贴无导线的引脚时以该引脚建立伪连通组参与合并。
- **悬空名字（标签/电源标识符无对端）**：合并后，单一网络名在整张原理图内仅覆盖 1 个连通组 —— 名字没有连到任何对端 —— 判为单连接；此时即使组内器件已通过导线直连（如 R13 与 U8 直连、EN2.8V 标签无对端）仍会报告。网络名覆盖 ≥ 2 个连通组视为名字生效，不判单连接。
- **电源网络标识符（VCC / GND 等网络符号）视为有效连接**，挂有标识符的网络不判为单连接；但其名字仅覆盖 1 个连通组（悬空电源名，如误输入的 `MCU_3V3123`）时不豁免，仍判为单连接。
- 引脚设有**非连接标识（noConnect）** 的不计入孤立引脚。
- 与其他导线有交点、但全局仍只有一个网络名的网络同样会被识别并高亮（视觉上像连接，实际未连通）。

以上判定规则均可自定义（见下节）。

## 使用方法

1. 打开工程中任意一个原理图页面；
2. 菜单栏 **🔌 信号缺失检测** → **检测并高亮单连接网络**；
3. 插件检测当前图页所属板子的全部原理图页，沿问题导线绘制红色标记线（孤立引脚沿引脚方向画短标记），完成后 toast 提示发现数量；
4. 菜单 **查看检测报告...** 打开报告面板，点击 **定位** 可跳转到对应图页，画布自动缩放居中到目标网络（橙色聚焦标记），再次定位其他网络时自动重置上一次标记；
5. 菜单 **清除高亮** 移除全部标记线。

## 自定义设置

菜单 **设置...** 可修改以下配置（持久化保存，下次检测生效）：

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| 标记颜色 | `#e63228` | 高亮标记线颜色（`#rrggbb`） |
| 标记线宽 | 3 | 1 ~ 10 |
| 器件数阈值 | 1 | 器件数 ≤ 阈值判为单连接；0 = 仅报告无器件连接的网络（悬空标签判定同时关闭） |
| 电源标识符视为有效连接 | 开 | 关闭后挂有 VCC/GND 等标识符的网络也参与单连接判定；名字悬空（仅覆盖 1 个连通组）的电源名不受此开关豁免，始终参与判定 |
| 短接符号视为导线连接 | 开 | 关闭后短接符号不参与连通性合并 |
| 检测项开关 | 全开 | 单连接 / 无器件连接 / 未命名网络 / 悬空导线 / 孤立引脚，可单独关闭 |

## 菜单项

- 检测并高亮单连接网络（`detectAndHighlight`）
- 清除高亮（`clearHighlight`）
- 查看检测报告...（`openReport`）
- 设置...（`openConfig`）
